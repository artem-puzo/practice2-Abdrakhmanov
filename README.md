## Вопросы

### 1. Чем переменная SCSS отличается от CSS Custom Property?
- **SCSS (`$var`):** Вычисляется при компиляции в статический CSS. Браузер ничего не знает о переменных SCSS.
- **CSS Custom Property (`var(--var)`):** Работает в режиме реального времени (runtime) прямо в браузере, динамически меняется через JS и каскад CSS.

### 2. Зачем нужны partial-файлы (начинающиеся с `_`)?
Префикс `_` (например, `_variables.scss`) запрещает компилятору Sass создавать отдельный файл `.css`. Файл используется только как подключаемый модуль через `@use`.

### 3. Где применён Mixin?
Миксин `@mixin container` задан в `scss/_mixins.scss` (максимальная ширина и центрирование) и подключён с помощью `@use` в `scss/_layout.scss` к блоку `header`.
